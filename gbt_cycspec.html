Analysing GBT Cyclic Spectroscopy Data

Here, I will describe the steps needed to analyze NANOGrav pulsar observations taken with the GBT's Cyclic Spectroscopy backend.

  • First, locate the data. On a GBT machine like Planck, go to the directory: /stor/gbtdata/. Then, look in any one of the directories beginning with: AGBT24B_427_* in the CYCSPEC folder. Data from each bank can be found in folders A-H (the data in each of these directories corresponds to a different frequency range; later letters seem to have lower frequencies (not sure if this is true across the board or just for the data I was looking at, though).
  • Copy the fits files from your desired folder to your working directory.
  • Combine these fits files into one large fits file for easier analysis using psradd. Commands take the following form: 
    psradd -o [output fits name] [prefix of input fits files]*fits
  • Once you have your new fits file, you can do some quick checks to make sure things look reasonable so far; check the pulse profile to see if you get a reasonable SNR using: 
    pav -DFTp [fitsname.fits]
    and check the dynamic spectrum using: 
    pav -j [fitsname.fits]
  • Now we want to prepare a dynamic spectrum file so we can do some analysis using Daniel Reardon's scintools package. Jacob Turner provided some helpful scripts for this! Use the script in: 
    /home/scratch/jturner/get_scint_files_temp_match_filename.py
    (on the GBO machines) to create a dynamic spectrum numpy array, saved as a pickle file. Then, convert that pickle file to a scintools-compatible format using the script: 
    /home/scratch/emwhite/cycspec/make_scintools_dynspec.py
    (also written by Jacob Turner, I just copied it into my area). You can run these scripts as follows:
    • python get_scint_files_temp_match_filename.py [fitsname.fits]
    • python make_scintools_dynspec.py [picklename.pickle]
      (note the output is a .txt file)
  • We can now plot both the dynamic and secondary spectra using scintools! I have written a simple script to do this, here: 
    /home/scratch/emwhite/cycspec/plot_dynspec.py
    Just replace the directory path with that corresponding to your own files and it should work.

And there you have it, a pretty straightforward way to get some initial information out of your data. Next I'd like to figure out how to splice the output from multiple frequency banks together. Thanks to Jacob Turner for his troubleshooting help, which made this set of instructions possible!
